# Mujassam · مجسّم

Interactive website for **Mujassam**: natural language → validated CAD in real millimetres → STEP / STL / GLB.

A small workshop robot, built in 3D with three.js, follows your cursor and guides you through the site.

## Run it

It is a static site with no build step. Serve the folder and open it in a browser:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Opening `index.html` directly from disk also works. three.js (r128), JSZip and Google Fonts load from CDNs, so you need an internet connection.

To publish it with GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch**, pick the branch and `/ (root)`.

## Project structure

```
index.html              markup for every page (hash-routed single page app)
assets/css/styles.css   blueprint theme, layout, responsive rules
assets/js/app.js        router, 3D scenes, Studio pipeline, exporters
```

## Pages

The site is one `index.html` with hash routes:

| Route | Page |
|---|---|
| `#home` | Landing page: the robot acts out the pipeline as you scroll |
| `#studio` | The generator: prompt panel, 3D viewport, spec, pipeline tracker, downloads, history |
| `#how` | Technical deep dive: interactive workflow, the scale problem, recipe RAG, compiler vs QLoRA, validation chain |
| `#library` | The 8 engineering families with rotating previews and "Open in Studio" |
| `#results` | Lab notebook (on hold while results are re-run on the new dataset) |
| `#about` | The team |
| `#guide` | Prompt guide with a live prompt checker |
| anything else | 404: "This page came out at 0.0188 scale." |

## What you can do on the site

- **Home**: the robot follows your cursor; scroll to watch it act out each pipeline stage.
- **Gallery**: drag a part to orbit it, hover for its dimensions, toggle x-ray.
- **Try it**: pick a preset and the robot welds it layer by layer.
- **Studio**: describe a part (or pick an example) and press Generate. The browser demo parses the spec, picks a recipe, builds the part in real millimetres, runs the four validation checks and unlocks downloads. Drag to orbit, scroll to zoom, toggle x-ray and dimensions, and reopen earlier parts from History.
- **Downloads**: real binary STL, GLB (in metres, per glTF) and the generated CadQuery `.py`, whose last line writes the STEP file when run with CadQuery.
- **How it works**: click any box in the workflow diagram; drag the slider to compare stretching each axis with building in real mm.
- **Prompt guide**: type a request and the live checker scores it out of 5, then opens it in Studio.

Bearing mounts, sensor brackets and shaft collars are compiled in the browser. Plates and every other part are sent to the QLoRA backend: the [Mujassam Space](https://huggingface.co/spaces/AlreemDoss/mujassam) runs Qwen2.5-Coder-7B with the [Mujassam V5 adapter](https://huggingface.co/AlreemDoss/mujassam-qwen7b-qlora), executes and measures the CadQuery, and returns STEP, STL and GLB. If the backend can't be reached, plates fall back to the browser template.

To point Studio at another backend (for example a local `python app.py` of the Space), open the site with `?backend=http://127.0.0.1:7860`.

## Landing page sections

1. **Hero**: the robot at its workbench, following your cursor.
2. **The scale problem**: a 60 × 40 × 5 mm plate starts as a speck and grows to true size.
3. **How it works**: read the spec → recipe RAG → the fork (deterministic compiler / corrected QLoRA fallback) → validation gate → export.
4. **Live demo gallery**: bearing mount, sensor bracket and shaft collar on turntables, with x-ray and hover dimensions.
5. **Try it**: presets that the robot welds layer by layer.
6. **Honest results**: results are being re-run on the new dataset; links to the Results page.
7. **Footer CTA**.

## Languages

| Language | Where |
|---|---|
| HTML5 | `index.html`: page markup, forms, inline SVG icon |
| CSS3 | `assets/css/styles.css`: custom properties, grid/flex layout, media queries, keyframe animations |
| JavaScript (ES2017+) | `assets/js/app.js`: routing, three.js/WebGL scenes, spec parser, STL/GLB export |
| SVG | the lock icon and the stretch-vs-mm demo, which is drawn at runtime |
| Python (CadQuery) | generated by the Studio as text and offered as a `.py` download |
